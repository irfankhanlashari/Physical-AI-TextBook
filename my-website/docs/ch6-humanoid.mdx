## Introduction to Humanoid Robotics

Humanoid robots are designed with human-like characteristics, including a torso, head, two arms, and two legs. These robots present unique challenges in control, balance, and interaction due to their complex kinematics and the need to operate in human-designed environments.

Key aspects of humanoid robotics:
- **Bipedal locomotion**: Walking on two legs like humans
- **Human-like manipulation**: Using arms and hands similar to humans
- **Social interaction**: Designed to interact naturally with humans
- **Environment compatibility**: Operating in spaces designed for humans

### Key Design Considerations

#### Degrees of Freedom (DOF)
The number of independent movements a humanoid robot can make:
- **High DOF**: More flexibility but complex control
- **Low DOF**: Easier control but limited movement
- Typical humanoid robots have 20-40+ DOF

#### Actuation Systems
- **Electric motors**: Precise control, good for indoor applications
- **Hydraulic systems**: High power-to-weight ratio, for dynamic movement
- **Pneumatic systems**: Compliance and safety benefits
- **Series elastic actuators**: Improved force control and safety

## Sensor Systems for Humanoids

### Balance and Orientation Sensors

#### Inertial Measurement Units (IMUs)
Critical for balance and orientation:
- **Accelerometers**: Measure linear acceleration
- **Gyroscopes**: Measure angular velocity
- **Magnetometers**: Provide absolute orientation reference

```python
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Imu
from std_msgs.msg import Float64MultiArray


class HumanoidBalanceController(Node):
    def __init__(self):
        super().__init__('humanoid_balance_controller')

        # Subscribe to IMU data
        self.imu_sub = self.create_subscription(
            Imu,
            '/imu/data',
            self.imu_callback,
            10
        )

        # Publishers for joint control
        self.joint_cmd_pub = self.create_publisher(
            Float64MultiArray,
            '/joint_group_position_controller/commands',
            10
        )

        # Balance control parameters
        self.roll = 0.0
        self.pitch = 0.0
        self.yaw = 0.0
        self.zmp_x = 0.0
        self.zmp_y = 0.0

    def imu_callback(self, msg):
        # Extract orientation from IMU quaternion
        import math
        q = msg.orientation

        # Convert quaternion to roll, pitch, yaw
        sinr_cosp = 2 * (q.w * q.x + q.y * q.z)
        cosr_cosp = 1 - 2 * (q.x * q.x + q.y * q.y)
        self.roll = math.atan2(sinr_cosp, cosr_cosp)

        sinp = 2 * (q.w * q.y - q.z * q.x)
        if abs(sinp) >= 1:
            self.pitch = math.copysign(math.pi / 2, sinp)
        else:
            self.pitch = math.asin(sinp)

        siny_cosp = 2 * (q.w * q.z + q.x * q.y)
        cosy_cosp = 1 - 2 * (q.y * q.y + q.z * q.z)
        self.yaw = math.atan2(siny_cosp, cosy_cosp)

        # Implement balance control based on IMU data
        self.balance_correction()

    def balance_correction(self):
        # Simple balance correction based on orientation
        if abs(self.roll) > 0.1:  # If tilted beyond 5.7 degrees
            # Send corrective joint commands
            cmd_msg = Float64MultiArray()
            cmd_msg.data = [0.0] * 25  # Assuming 25 joints
            # Adjust ankle joints to correct roll
            # Left ankle adjustment
            cmd_msg.data[10] = -self.roll * 0.5  # Ankle roll
            # Right ankle adjustment
            cmd_msg.data[15] = -self.roll * 0.5  # Ankle roll

            self.joint_cmd_pub.publish(cmd_msg)
```

## Control Systems and Algorithms

### Balance Control

#### Zero Moment Point (ZMP)
The ZMP is a critical concept in humanoid balance:
- Point where the sum of all moments equals zero
- Must remain within support polygon for stability
- Used in gait planning and balance control

```python
import numpy as np


class ZMPController:
    def __init__(self):
        # Robot parameters
        self.com_height = 0.8  # Center of mass height (m)
        self.gravity = 9.81
        self.omega = np.sqrt(self.gravity / self.com_height)

        # Support polygon (simplified as rectangle)
        self.foot_length = 0.2  # m
        self.foot_width = 0.1   # m

    def compute_zmp(self, com_pos, com_vel, com_acc):
        """
        Compute ZMP from center of mass information
        ZMP_x = CoM_x - (CoM_height * CoM_acc_x) / gravity
        ZMP_y = CoM_y - (CoM_height * CoM_acc_y) / gravity
        """
        zmp_x = com_pos[0] - (self.com_height * com_acc[0]) / self.gravity
        zmp_y = com_pos[1] - (self.com_height * com_acc[1]) / self.gravity

        return np.array([zmp_x, zmp_y, 0.0])

    def check_stability(self, zmp):
        """
        Check if ZMP is within support polygon
        """
        # Simplified support polygon check
        x_limit = self.foot_length / 2
        y_limit = self.foot_width / 2

        return (abs(zmp[0]) <= x_limit and abs(zmp[1]) <= y_limit)
```

#### Footstep Planning
- Determine optimal footstep locations
- Consider obstacle avoidance
- Maintain balance throughout gait

```python
class FootstepPlanner:
    def __init__(self):
        self.step_length = 0.3  # m
        self.step_width = 0.2   # m
        self.step_height = 0.05 # m (clearance)

    def plan_footsteps(self, start_pos, goal_pos, step_length=None):
        """
        Plan sequence of footsteps from start to goal
        """
        if step_length is None:
            step_length = self.step_length

        # Calculate number of steps needed
        distance = np.linalg.norm(goal_pos[:2] - start_pos[:2])
        num_steps = int(np.ceil(distance / step_length))

        footsteps = []
        for i in range(num_steps):
            # Interpolate between start and goal
            ratio = (i + 1) / num_steps
            step_pos = start_pos + (goal_pos - start_pos) * ratio

            # Alternate between left and right foot
            if i % 2 == 0:
                # Add step width offset for right foot
                step_pos[1] += self.step_width / 2
            else:
                # Add step width offset for left foot
                step_pos[1] -= self.step_width / 2

            footsteps.append(step_pos)

        return footsteps
```
