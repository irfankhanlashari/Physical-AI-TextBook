# Chapter 7: Conversational Robotics

## Learning Objectives

By the end of this chapter, you should be able to:

- Understand the principles of conversational AI in robotics

- Integrate speech recognition and natural language processing

- Evaluate conversational robot performance and usability

## Introduction to Conversational Robotics

Conversational robotics combines natural language processing, speech recognition, and dialogue management to enable intuitive human-robot interaction. These systems allow users to communicate with robots using natural language, making robotic systems more accessible and user-friendly.

Key components of conversational robotics:
- **Automatic Speech Recognition (ASR)**: Converting speech to text
- **Natural Language Understanding (NLU)**: Interpreting user intent
- **Dialogue Management**: Maintaining conversation state and flow
- **Natural Language Generation (NLG)**: Producing appropriate responses
- **Text-to-Speech (TTS)**: Converting text responses to speech

## Architecture of Conversational Systems

### System Components

```
User Speech → ASR → NLU → Dialogue Manager → NLG → TTS → Robot Response
                    ↓
               Robot Action Execution
```

### Speech Recognition (ASR)

#### Overview
Automatic Speech Recognition converts spoken language into text. Key considerations for robotics include:

- **Real-time processing**: Low-latency recognition for natural interaction
- **Noise robustness**: Performance in noisy environments
- **Speaker adaptation**: Adjusting to different speakers
- **Vocabulary constraints**: Limited vocabulary for efficiency

#### Implementation Example

```python
import speech_recognition as sr
import rclpy
from rclpy.node import Node
from std_msgs.msg import String


class SpeechRecognizer(Node):
    def __init__(self):
        super().__init__('speech_recognizer')

        # Initialize speech recognition
        self.recognizer = sr.Recognizer()
        self.microphone = sr.Microphone()

        # Adjust for ambient noise
        with self.microphone as source:
            self.recognizer.adjust_for_ambient_noise(source)

        # Publisher for recognized text
        self.text_pub = self.create_publisher(
            String,
            '/recognized_text',
            10
        )

        # Start listening loop
        self.listen_for_speech()

    def listen_for_speech(self):
        while True:
            try:
                with self.microphone as source:
                    # Listen for speech with timeout
                    audio = self.recognizer.listen(source, timeout=5.0, phrase_time_limit=10.0)

                # Recognize speech using Google's service
                text = self.recognizer.recognize_google(audio)
                self.get_logger().info(f"Recognized: {text}")

                # Publish recognized text
                msg = String()
                msg.data = text
                self.text_pub.publish(msg)

            except sr.WaitTimeoutError:
                # No speech detected, continue listening
                pass
            except sr.UnknownValueError:
                self.get_logger().info("Could not understand audio")
            except sr.RequestError as e:
                self.get_logger().error(f"Could not request results; {e}")


def main(args=None):
    rclpy.init(args=args)
    speech_recognizer = SpeechRecognizer()
    rclpy.spin(speech_recognizer)
    speech_recognizer.destroy_node()
    rclpy.shutdown()
```

### Natural Language Understanding (NLU)

#### Intent Recognition
Identifying the user's intent from natural language:

```python
from transformers import pipeline
import json


class IntentClassifier:
    def __init__(self):
        # Load pre-trained model for intent classification
        self.classifier = pipeline(
            "text-classification",
            model="microsoft/DialoGPT-medium"
        )

        # Define intent mappings
        self.intent_map = {
            "navigation": ["go to", "move to", "navigate to", "walk to"],
            "greeting": ["hello", "hi", "hey", "good morning"],
            "question": ["what", "where", "when", "how", "why"],
            "command": ["pick up", "grasp", "take", "bring", "get"],
            "farewell": ["bye", "goodbye", "see you", "thank you"]
        }

    def classify_intent(self, text):
        # Simple keyword-based classification
        text_lower = text.lower()

        for intent, keywords in self.intent_map.items():
            if any(keyword in text_lower for keyword in keywords):
                return intent

        # Use transformer model for more complex classification
        result = self.classifier(text)
        return result[0]['label']
```

#### Entity Extraction
Identifying specific entities mentioned in user input:

```python
import spacy


class EntityExtractor:
    def __init__(self):
        # Load spaCy model
        self.nlp = spacy.load("en_core_web_sm")

    def extract_entities(self, text):
        doc = self.nlp(text)

        entities = {
            'PERSON': [],
            'ORG': [],
            'GPE': [],  # Geopolitical entity
            'MONEY': [],
            'DATE': [],
            'TIME': [],
            'CARDINAL': [],
            'OBJECT': []  # Custom object recognition
        }

        # Extract standard entities
        for ent in doc.ents:
            if ent.label_ in entities:
                entities[ent.label_].append(ent.text)

        # Extract objects using custom logic
        # This could involve object detection integration
        object_keywords = ["ball", "box", "cup", "book", "table", "chair"]
        for token in doc:
            if token.lemma_ in object_keywords:
                entities['OBJECT'].append(token.text)

        return entities
```

### Dialogue Management

#### State Management
Maintaining conversation context and history:

```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import String
from geometry_msgs.msg import Pose


class DialogueManager(Node):
    def __init__(self):
        super().__init__('dialogue_manager')

        # Subscribe to recognized text
        self.text_sub = self.create_subscription(
            String,
            '/recognized_text',
            self.text_callback,
            10
        )

        # Publisher for robot commands
        self.command_pub = self.create_publisher(
            String,
            '/robot_command',
            10
        )

        # Publisher for speech responses
        self.speech_pub = self.create_publisher(
            String,
            '/speech_output',
            10
        )

        # Conversation state
        self.conversation_state = {
            'current_topic': 'greeting',
            'user_context': {},
            'task_in_progress': None,
            'last_intent': None,
            'entities': {}
        }

        # Initialize NLU components
        self.intent_classifier = IntentClassifier()
        self.entity_extractor = EntityExtractor()

    def text_callback(self, msg):
        text = msg.data
        self.get_logger().info(f"Processing: {text}")

        # Classify intent
        intent = self.intent_classifier.classify_intent(text)

        # Extract entities
        entities = self.entity_extractor.extract_entities(text)

        # Update conversation state
        self.conversation_state['last_intent'] = intent
        self.conversation_state['entities'] = entities

        # Generate response based on intent
        response = self.generate_response(intent, entities, text)

        # If the intent requires a robot action, publish command
        if intent in ['navigation', 'command']:
            self.execute_robot_action(intent, entities)

        # Publish speech response
        speech_msg = String()
        speech_msg.data = response
        self.speech_pub.publish(speech_msg)

    def generate_response(self, intent, entities, original_text):
        responses = {
            'greeting': "Hello! How can I help you today?",
            'farewell': "Goodbye! Have a great day!",
            'navigation': f"I can help you navigate. Where would you like to go?",
            'command': f"I can assist with tasks. What would you like me to do?",
            'question': "I'm here to help. What would you like to know?"
        }

        if intent in responses:
            return responses[intent]
        else:
            return "I understand. How else can I assist you?"

    def execute_robot_action(self, intent, entities):
        command_msg = String()

        if intent == 'navigation':
            # Extract destination from entities
            destination = entities.get('GPE', entities.get('OBJECT', ['default_location']))
            if destination:
                command_msg.data = f"navigate_to:{destination[0]}"
            else:
                command_msg.data = "navigate_to:unknown_location"
        elif intent == 'command':
            # Extract object and action
            obj = entities.get('OBJECT', ['default_object'])
            command_msg.data = f"manipulate:{obj[0]}"

        self.command_pub.publish(command_msg)
```

### Natural Language Generation (NLG)

#### Response Generation

```python
import random


class ResponseGenerator:
    def __init__(self):
        self.responses = {
            'greeting': [
                "Hello! How can I assist you?",
                "Hi there! What can I do for you?",
                "Good day! How may I help you?"
            ],
            'navigation': [

                "Sure, I'll navigate to that location.",
                "I'll show you the way."
            ],
            'command': [
                "I'll do that for you.",
                "Okay, I'll take care of that.",
                "I can help with that task."
            ],
            'question': [
                "I can provide information about that.",
                "Let me help you with that question.",
                "I know about that topic."
            ],
            'error': [
                "I'm sorry, I didn't understand that.",
                "Could you please repeat that?",
                "I'm not sure I understood correctly."
            ]
        }

    def generate_response(self, intent, context=None):
        if intent in self.responses:
            return random.choice(self.responses[intent])
        else:
            return random.choice(self.responses['error'])
```

### Text-to-Speech (TTS)

#### Implementation Example

```python
import pyttsx3
import rclpy
from rclpy.node import Node
from std_msgs.msg import String


class TextToSpeech(Node):
    def __init__(self):
        super().__init__('text_to_speech')

        # Subscribe to speech output
        self.speech_sub = self.create_subscription(
            String,
            '/speech_output',
            self.speech_callback,
            10
        )

        # Initialize TTS engine
        self.tts_engine = pyttsx3.init()

        # Configure speech properties
        self.tts_engine.setProperty('rate', 150)  # Speed of speech
        self.tts_engine.setProperty('volume', 0.9)  # Volume level

    def speech_callback(self, msg):
        text = msg.data
        self.get_logger().info(f"Speaking: {text}")

        # Speak the text
        self.tts_engine.say(text)
        self.tts_engine.runAndWait()
```

#### Action Integration

```python
import rclpy
from rclpy.action import ActionClient
from rclpy.node import Node
from your_robot_msgs.action import NavigateToPose
from std_msgs.msg import String


class ConversationalNavigation(Node):
    def __init__(self):
        super().__init__('conversational_navigation')

        # Create action client for navigation
        self.nav_client = ActionClient(
            self,
            NavigateToPose,
            'navigate_to_pose'
        )

        # Subscribe to navigation commands from dialogue manager
        self.nav_cmd_sub = self.create_subscription(
            String,
            '/navigation_command',
            self.nav_command_callback,
            10
        )

    def nav_command_callback(self, msg):
        # Parse navigation command
        command_parts = msg.data.split(':')
        if command_parts[0] == 'navigate_to' and len(command_parts) > 1:
            destination = command_parts[1]
            self.navigate_to_location(destination)

    def navigate_to_location(self, location):
        # Wait for action server
        self.nav_client.wait_for_server()

        # Create goal
        goal_msg = NavigateToPose.Goal()
        goal_msg.pose = self.get_location_pose(location)

        # Send goal
        self.nav_client.send_goal_async(
            goal_msg,
            feedback_callback=self.nav_feedback_callback
        )

    def get_location_pose(self, location_name):
        # In a real system, this would look up pre-defined locations
        # For this example, we'll return a default pose
        from geometry_msgs.msg import Pose
        pose = Pose()
        pose.position.x = 1.0  # Example coordinates
        pose.position.y = 1.0
        pose.orientation.w = 1.0
        return pose

    def nav_feedback_callback(self, feedback_msg):
        self.get_logger().info(f"Navigation progress: {feedback_msg.feedback.distance_remaining}")
```

## Context and Memory Management

### Maintaining Conversation History

```python
from collections import deque
import json


class ConversationMemory:
    def __init__(self, max_history=10):
        self.history = deque(maxlen=max_history)
        self.user_context = {}
        self.long_term_memory = {}

    def add_interaction(self, user_input, bot_response, timestamp=None):
        interaction = {
            'user_input': user_input,
            'bot_response': bot_response,
            'timestamp': timestamp or time.time(),
            'entities': self.extract_entities(user_input)
        }
        self.history.append(interaction)

    def get_recent_context(self, n=3):
        return list(self.history)[-n:]

    def update_user_context(self, user_id, context_data):
        if user_id not in self.user_context:
            self.user_context[user_id] = {}
        self.user_context[user_id].update(context_data)

    def get_user_context(self, user_id):
        return self.user_context.get(user_id, {})
```

## Advanced Dialogue Features

### Multi-turn Conversations

Handling conversations that span multiple exchanges:

```python
class MultiTurnDialogue:
    def __init__(self):
        self.active_dialogues = {}  # Maps user_id to dialogue state

    def process_input(self, user_id, text):
        if user_id not in self.active_dialogues:
            # Start new dialogue
            self.active_dialogues[user_id] = {
                'state': 'idle',
                'context': {},
                'task': None
            }

        dialogue_state = self.active_dialogues[user_id]

        # Process input based on current dialogue state
        if dialogue_state['state'] == 'idle':
            return self.handle_idle_state(user_id, text, dialogue_state)
        elif dialogue_state['state'] == 'task_in_progress':
            return self.handle_task_state(user_id, text, dialogue_state)
        elif dialogue_state['state'] == 'awaiting_confirmation':
            return self.handle_confirmation_state(user_id, text, dialogue_state)

    def handle_idle_state(self, user_id, text, dialogue_state):
        # Classify intent and start appropriate task
        intent = self.intent_classifier.classify_intent(text)

        if intent == 'navigation':
            dialogue_state['state'] = 'task_in_progress'
            dialogue_state['task'] = 'navigation'
            return "Where would you like to go?"
        elif intent == 'command':
            dialogue_state['state'] = 'task_in_progress'
            dialogue_state['task'] = 'manipulation'
            return "What would you like me to do?"
        else:
            return self.default_response(text)

    def handle_task_state(self, user_id, text, dialogue_state):
        # Handle input related to the current task
        if dialogue_state['task'] == 'navigation':
            # Extract destination and confirm
            entities = self.entity_extractor.extract_entities(text)
            destination = entities.get('GPE', entities.get('OBJECT', ['unknown']))

            dialogue_state['context']['destination'] = destination[0]
            dialogue_state['state'] = 'awaiting_confirmation'

            return f"Did you say {destination[0]}?"
```

### Contextual Understanding

Understanding references and maintaining context:

```python
class ContextualUnderstanding:
    def __init__(self):
        self.pronoun_resolver = PronounResolver()
        self.coreference_resolver = CoreferenceResolver()

    def resolve_references(self, text, conversation_history):
        # Resolve pronouns like "it", "that", "there"
        resolved_text = self.pronoun_resolver.resolve(text, conversation_history)

        # Resolve other references
        resolved_text = self.coreference_resolver.resolve(resolved_text, conversation_history)

        return resolved_text


class PronounResolver:
    def resolve(self, text, history):
        # Simple pronoun resolution
        # In practice, this would use more sophisticated NLP
        text_lower = text.lower()

        if 'it' in text_lower or 'that' in text_lower:
            # Look for the last mentioned object in history
            for interaction in reversed(history):
                entities = interaction.get('entities', {})
                objects = entities.get('OBJECT', [])
                if objects:
                    # Replace pronoun with the last mentioned object
                    text = text.replace('it', objects[-1])
                    text = text.replace('that', objects[-1])
                    break

        return text
```

## Evaluation and Usability

### Metrics for Conversational Systems

#### Objective Metrics
- **Recognition accuracy**: Percentage of correctly recognized speech
- **Intent classification accuracy**: Correct intent identification
- **Response time**: Latency from input to response
- **Task completion rate**: Successful completion of requested tasks

#### Subjective Metrics
- **Naturalness**: How natural the conversation feels
- **Helpfulness**: How well the robot addresses user needs
- **Satisfaction**: User satisfaction with the interaction
- **Ease of use**: How easy it is to interact with the robot

### Usability Testing

#### Wizard of Oz Testing
- Human operator simulates robot responses
- Tests dialogue flow and user expectations
- Identifies potential interaction issues

#### User Studies
- Real users interact with the system
- Collects quantitative and qualitative feedback
- Validates system effectiveness

## Privacy and Ethical Considerations

### Data Privacy
- **Voice data collection**: Minimize stored voice recordings
- **Conversation logging**: Secure and anonymize conversation data
- **User consent**: Clear consent for data collection and use

### Ethical Guidelines
- **Transparency**: Users know they're interacting with a robot
- **Appropriate expectations**: Don't over-promise capabilities
- **Safety**: Ensure responses don't cause harm
- **Bias mitigation**: Address potential biases in responses

## Implementation Challenges

### Real-time Processing
- **Latency constraints**: Keep response times low for natural interaction
- **Resource optimization**: Efficient use of computational resources
- **Parallel processing**: Handle multiple components simultaneously

### Noise and Environmental Factors
- **Acoustic challenges**: Background noise, reverberation
- **Microphone positioning**: Optimal placement for speech capture
- **Adaptive algorithms**: Adjust to changing acoustic conditions

### Robustness
- **Error recovery**: Handle recognition and understanding failures
- **Fallback strategies**: Graceful degradation when systems fail
- **User guidance**: Help users when interaction fails

## Future Directions

### Advanced AI Integration
- **Large Language Models**: Integration with models like GPT for better responses
- **Multimodal interaction**: Combining speech with gestures and visual input
- **Emotional intelligence**: Recognizing and responding to user emotions

### Personalization
- **Adaptive responses**: Learning from individual user preferences
- **Context-aware interaction**: Using environmental and user context
- **Long-term relationship building**: Maintaining user profiles over time

## Best Practices

### Design Principles
1. **Keep it simple**: Start with basic, reliable functionality
2. **Provide feedback**: Always acknowledge user input
3. **Handle errors gracefully**: Have clear error recovery paths
4. **Maintain context**: Remember relevant conversation history
5. **Respect user privacy**: Be transparent about data handling

### Development Guidelines
1. **Modular architecture**: Separate components for easier maintenance
2. **Extensive testing**: Test with diverse users and scenarios
3. **Continuous improvement**: Use interaction logs to improve the system
4. **Documentation**: Clearly document system components and interfaces
